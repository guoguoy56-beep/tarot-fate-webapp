# 毕设演示视频录制顺序

先在终端运行 `npm run demo`，打开 `http://127.0.0.1:3000`。账号和随机密码在本机 `data/demo/accounts.json`，只在准备阶段查阅；正式录制只捕获网页窗口。保留演示数据和账号文件即可重复录制，不需要重新建库。

建议按下面顺序录制，可以分段剪辑：

1. **开场与首页**：展示载入图案、星空和牌流，介绍“命运回廊”与自我探索用途。
2. **登录**：用第一个演示账号登录，展示首页昵称、个人资料和刷新后登录状态仍保留。
3. **塔罗百科**：展示分类、检索和牌义详情，返回首页。
4. **完整占卜**：输入一个非隐私问题，如“如何安排接下来的学习？”，选择过去现在未来牌阵，展示入环、抽三张牌、逐牌翻转与解读，进入整体总结。
5. **个人手记**：保存本次示例，查看历史，展开问题、牌面、正逆位与保存时正文；刷新后再次查看。
6. **账号隔离**：退出第一个账号，登录第二个账号，展示其看不到第一个账号的记录。切回第一个账号，再展示原记录仍在。
7. **收尾**：展示退出登录。可补充一次游客抽牌后在保存时登录，说明登录保留了当次问题与牌面。

录制时准确描述当前交付范围：本轮预置账号使用真实服务端密码校验和数据库会话；注册、邮件验证及找回密码待后续实现。新版解读和总结仍为页面标注的示例，不应介绍为本次真实调用模型生成。账号密码文件、认证密钥、Cookie、开发工具与私人问题不应进入画面。

录制准备时可以先完成一条样例手记，方便拍摄历史与隔离；保留足够完整的点击和反馈，后期再剪掉输入或等待片段。最终源码包等剪辑完成、页面版本确定后再打包，排除本机账号、密钥、数据库、缓存、依赖和构建产物，并附可复现启动步骤。
