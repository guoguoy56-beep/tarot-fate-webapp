## 1. 字体分工

| 用途 | 字体 | 字重／字号原则 |
| --- | --- | --- |
| 首页主标题 | 本地 Noto Serif SC（Fate Serif） | 400，保留大标题及现有响应式尺寸，字距微调至 .06em |
| 牌名、章节标题、品牌及主入口 | 本地 Noto Serif SC | 常用 500，与正文区分 |
| 单牌解读、整体总结、百科和历史正文 | 本地 Noto Serif SC | 400；解读 18～21px，总结 18px，长文行高 2、字距 .02em |
| 导航、普通按钮、输入控件与紧凑标记 | 本地 Noto Sans SC（Fate Sans） | 常用 400／500，保留小字号操作的清晰度 |
| 英文副题与装饰数字 | 现有 Georgia／Times New Roman 回退 | 保留古典衬线风格，不增加第三套网络字体 |

以 CSS 变量统一显示、正文、控件和英文四类角色；不再让逐牌和总结正文使用不同字体。禁用合成字重，使用实际 400～600 可变字重资源。修正品牌／主入口字体被按钮继承规则覆盖的问题。准备说明、输入文字、百科和历史原有 11～13px 小正文适当提升至 13～15px。

## 2. 本地素材与许可

新增 `src/components/cosmic-fonts.css`，由新版组件引入。字体来自 Google Fonts 官方 CSS 的 Noto SC 分片，202 个 WOFF2 文件共 10,531,532 字节，保留上游 Unicode 范围；浏览器按实际字符加载所需分片，不预加载全量文件。

二进制未经修改，全部原始地址、字节数与 SHA-256 记录在 `public/assets/fonts/cosmic/SOURCES.json`，两份 OFL 许可及说明一并保留。接入只更改 CSS 家族别名和本地 URL，不依赖系统安装，不在构建或页面运行时向 Google 请求字体，无新增 npm 依赖。罕见字或未覆盖字符仍由现有系统回退栈处理。
