# FRONTEND-010：牌圈共享 3D 空间

日期：2026-11-04。接续 `d2c4101`，用户要求进入下一项并继续实施。本轮为第 11 项的第二步，在 `codex/continuous-space-3d` 迁移牌圈空间。字体检查点 `codex/frontend-rebuild`／`67d439a` 与旧版保留，论文不改。

## 1. 空间与渲染边界

新增 `CosmicRingSpace`：在上一轮的同一个 Three.js Scene 中建立牌圈 Group 与 78 个稳定身份的 Object3D 锚点。背景透视相机同时投影卡牌位置、计算相机深度及距离缩放；不再在正常运行中使用二维椭圆坐标与手写远近缩放决定牌圈位置。

圆环、阅读、总结的世界平面在窗口尺寸变化时按已认可的构图标定，再按现有阶段时钟插值世界中心和两个基向量。整组牌随公共转角运动，不重新洗牌、交换卡牌或改变选中语义。装饰轨道通过共享相机的投影矩阵生成 CSS 单应变换，与锚点处于同一空间平面；不额外创建 WebGL 重绘循环。

实现依据为官方 [Vector3](https://threejs.org/docs/pages/Vector3.html) 投影和 [Raycaster](https://threejs.org/docs/pages/Raycaster.html) 相机射线接口。当前使用混合渲染：Three.js 管理空间锚点与背景，原生按钮／CSS 3D 承载实际牌面和局部转向。牌面不是 WebGL 网格，未引入 CSS3DRenderer 重挂载 React 节点或新的依赖。

## 2. 交互与回退

- 鼠标两次位置分别生成相机射线，与牌圈世界平面相交，再变换到局部平面计算转角。前／后／左／右拖动跟随手势，保留释放惯性、匀速待机和悬停不停转。
- 78 张牌依相机真实深度生成唯一层级，选中只保留标记、轻微放大及边光；不额外抬升选中层级遮住邻牌。
- 1600ms 非线性入场、延迟翻面、到位前接入待机、10°上仰、四向 25°软阈值、松手追上原时间线及连续再抓取的局部动效不改。
- WebGL2 不可用时仍保留 CPU 相机与空间投影，背景使用 CSS 回退；贴图尚未就绪或 WebGL 上下文丢失时，牌圈计算继续进行。模块本身无法加载时保留旧椭圆回退。
- 继续复用原 RAF、卡牌按钮及资源，不新增相机待机晃动。卸载时移除场景锚点，并沿用上一轮的 GPU 资源清理。
