# FRONTEND-009：连续空间 3D 第一步

日期：2026-11-04。用户在字体版本 `67d439a` 后要求进入下一项。本轮先实施背景与相机迁移；工作分支为 `codex/continuous-space-3d`，原分支 `codex/frontend-rebuild` 保持在字体检查点。论文不改。

## 1. 本轮范围与实现依据

原背景是二维 CSS 图片的位移、缩放和旋转，卡牌已有独立 CSS 3D 动效。为保留用户已经调好的选牌、翻牌与拖拽，本轮先迁移背景与镜头：引入 Three.js `0.187.0`，使用同一个 Scene、PerspectiveCamera 和 WebGLRenderer 覆盖整个主流程；开发类型包固定为 `@types/three@0.187.0`，不增加 React Three Fiber 或新的动画框架。

实现依据为官方 [PerspectiveCamera](https://threejs.org/docs/pages/PerspectiveCamera.html)、[WebGLRenderer](https://threejs.org/docs/pages/WebGLRenderer.html)、[PointsMaterial](https://threejs.org/docs/pages/PointsMaterial.html) 与 [Texture](https://threejs.org/docs/pages/Texture.html) 文档。新增依赖的原因是现有 CSS 图片变换无法提供由真实空间深度产生的相机透视与星点视差。

## 2. 场景与镜头

- 沿用现有星云图片作为世界坐标中的固定绘景平面，配合远／中／近三个深度层的 650 个柔和星点；星点由代码生成，无新增图片素材。
- 首页保持原图的 cover 裁切、6% overscan 与 1.12 倍初始缩放，牌流起点继续对齐原星云漩涡。
- 提交问题后，镜头沿连续弧线向圆环空间穿行；进入阅读时继续推进并改变俯视方向；总结前拉开镜头并拓宽视野；返回首页沿现有状态平滑收回。
- 复用 `CosmicScene` 的现有 RAF 与入场时钟，不为背景另开独立动画循环，不在切换牌或阶段时重新创建场景、画布或贴图。
- 普通待机的镜头静止，不增加持续晃动；相机及尺寸未变化时跳过 WebGL 重绘。设备像素比上限为 1.5。

| 稳定阶段 | 相机位置 | 观察目标 | 垂直视角 |
| --- | --- | --- | --- |
| 首页 | (0, 0, 24) | (0, 0, −36) | 50° |
| 圆环 | (4, 1, 6) | (1, −1, −36) | 50° |
| 阅读 | (24, 3, −8) | (28, −10, −36) | 42° |
| 总结 | (15, 7, 3) | (16, −1, −36) | 47° |

上述为世界坐标，相机各阶段间持续插值；不是独立背景切换，也不是 UI 中向用户展示的参数。新增几何检查覆盖三种桌面比例的进入、阅读、总结和返回路径，避免相机视锥露出绘景边缘。

## 3. 回退与资源生命周期

Three.js 动态加载，原 CSS 背景一直保留在下面；只有贴图就绪、真实画面完成渲染后，画布才淡入。WebGL2 不可用、模块／贴图加载失败或上下文丢失时保持原背景可用，不阻止提问、选牌与阅读。上下文恢复后复用同一画布继续渲染。卸载时释放纹理、几何体、材质和渲染器。

减少动态偏好沿用既有直接到位规则，背景切换不淡入，静止后停止重复 WebGL 绘制。未修改系统图形设置、全局代理或环境文件。

现场复核发现 `.cosmic-scene` 在卡牌焦点移动后会因 `overflow: hidden` 成为可编程滚动容器，出现约 16.8px 内部滚动，画布随之上移并在底部露出旧背景。改为 `overflow: clip` 阻止该内部滚动；在 1159×668 的真实键盘选牌流程中验证画布四边与场景贴合、滚动偏移为 0。此修正只处理场景裁切，不改变卡牌投影或拖拽参数。
