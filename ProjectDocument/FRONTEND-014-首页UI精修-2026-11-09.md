# FRONTEND-014：首页 UI 精修

日期：2026-11-09。来源：本轮 grill-me 逐项访谈。首轮范围仅为桌面首页，先作为视觉样板，用户查看实际效果后再讨论其他界面。

## 1. 已确认的方向与内容

- 保留现有星空、3D 牌流、构图和占卜流程，左侧文字区继续居中排列。
- 采用轻盈精致的宋体气质、柔和金色、细边框与克制光晕，通过字号和留白区分主次。
- 保留主标题“命运回廊”，去掉上方“循星而来 · 向心而行”和英文小标题“CORRIDOR OF FATE”。
- 应用介绍采用“写下此刻的困惑，选择你的塔罗牌，开启一段自我探索的旅程。”。
- 开始入口采用轻描边胶囊，降低高度和底色厚重感，保留轻微悬停反馈。
- 去掉首页底部英文“THE STARS GUIDE. YOU DECIDE.”和中文“一段通往内心的旅程”。
- 右上导航采用无外框文字配细线图标，适当增大字号、统一间距，以柔和暗影改善亮背景上的可读性。

预期效果：第一眼聚焦应用名称，再阅读应用介绍并找到开始入口；减少辅助标语与厚重控件，让星空和牌流周围保留更多留白。

## 2. 首轮实现

首页左侧收敛为标题、两行介绍和开始按钮三层。左边距与区域宽度仍为视口的 8% 和 36%，内容居中；去掉辅助文案后将容器顶部调整到 28%，维持主内容处于画面中上部。

标题使用原宋体，字号为 `clamp(64px, 6.3vw, 112px)`、颜色 `#e2cda5`，移除金色光晕。介绍使用 16～19px 字号与 1.95 行高，在“选择你的塔罗牌，”之后换行。按钮最小宽度从 310px 调为 260px，字号从 25px 调为 18～21px，垂直内边距从 19px 调为 14px；首页专用样式覆盖原来的内描边和厚重底色，不改其他阶段的通用按钮。

导航文字由 14px 调为 15px，图标统一为 16px、1.3 线宽，间隔为 32px；保留既有较窄桌面的 23px 间隔。去掉登录前分隔线，让三个入口以一致间距排列。页脚仅在首页不渲染，提问等阶段的示例说明与原页脚仍保留。

仅修改 `CosmicExperience.tsx` 中首页相关 JSX 与 `cosmic-experience.css` 中首页相关规则。镜头、牌组、牌面资源、提问组件、后端和存储均不属于本轮修改内容。

## 4. 首页反馈：单行描述与参考图按钮

用户查看首版后明确要求：描述完整放在一行，标题、描述、按钮上下留白保持视觉均衡；原先普通描边胶囊缺少最初产品预览图的按钮感觉。本节替代前文中“两行介绍”和“普通细边胶囊”的实现约定。

用户随后追加要求：首页标题和“开始占卜”文字的字形、金属效果也要与最初产品图一样，允许采用任何实现方法。最终采用原图像素提取，保留原字形与纹理。

已重新打开并核对原选方案 2 `homepage-option-02-nebula-voyage.png`。直接提取其标题与完整按钮，得到 `home-title-source-v1.png`（462×144）和 `start-button-source-v1.png`（425×115）。只计算透明通道，输出 RGB 与对应原图裁区逐字节一致；保留标题长笔画、金色渐变、材质纹理，以及按钮原有文字、双层金边、星芒、深色底和光点。来源、裁区和可复现脚本见 [素材记录](./frontend-handoff-assets/homepage-source-lettering.md)。未采用重新绘制的近似字形，原预览图保持原样。

描述保持完整单段与 `white-space: nowrap`，字号随桌面宽度在 15～19px 之间变化。左侧三层用 flex 居中、基础间距 32px；标题按素材本体高度参与排版，按钮加 6px 光学补偿，使描述上下视觉留白协调。标题宽 330～480px，按钮宽 310～425px，素材均保持自然比例。

`h1` 和原生 `button` 保留可读的 `sr-only` 名称，图像仅承担视觉字形；辅助技术仍识别“命运回廊”和“开始占卜”。图片优先加载并使用 `unoptimized`，防止损耗压缩改变原图金属纹理。按钮命中／焦点区为 5:1，图片以自然比例居中；保留悬停／聚焦亮度、按下反馈、Enter 启动、准备完毕前禁用及减少动态设置。

验证：lint、类型检查、生产构建通过。在应用内浏览器检查 1280×720、1484×1060、1850×959；1280 宽实测描述只有一行、左右约 100～566px，标题宽约 399px、按钮约 358px；1850 宽标题 480px、按钮 425px。实际验证 Tab 焦点、Enter 进入提问及返回首页，控制台 error 为空。原图与实现整图、标题及按钮细节已合并对照并查看，见 `output/home-ui-ornate-2026-11-09/source-full-comparison.jpg`、`source-type-comparison.jpg`；逐像素 RGB 校验见同目录 `source-pixel-verification.json`，根目录 `design-qa.md` 记录最新设计核对。
