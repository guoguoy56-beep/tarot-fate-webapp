# 星空前端素材

2026-11-02 建立，2026-11-04 增加并细调新版牌背，供 `CosmicExperience` 使用。当前牌背为 v2，v1 保留供回滚。素材通过内置 Image Gen 生成，背景与轨道不包含 UI 或卡牌平面；78 张 RWS 正面继续使用项目既有资源。

背景参考 `ProjectDocument/frontend-handoff-assets/` 的方案 2、3；提示词要求无卡牌、无文字/UI、无大行星、无前景碎石。背景系找回前次已成功生成的原图后复制，避免重复生成。

轨道参考方案 1；提示词要求俯视、细线、稀疏刻度节点、无卡牌/文字/行星/UI/光雾。内置工具实际输出 1254 方图，未遵循请求的 1536；保留原始分辨率，没有插值放大。原始生成文件保留在 Codex 本地生成目录。

概念图只用于设计对齐，没有作为整张网页截图铺到界面。所有卡牌、文字、按钮、表单和面板均为独立交互元素。

牌背 v1 原图为 962×1635 PNG，通过项目已有 Sharp 归一至卡牌 17:29 比例并以 quality 90 编码 WebP。这是首轮处理记录；当前 v2 取消缩小与有损编码。单张运行图片由全部 78 个牌背节点复用，适用于首页流动、圆环选牌和阅读翻面。

用户反馈 v1 与星云颜色接近且前景不够清晰后，以内置 Image Gen 编辑原母图，保留主要星盘、月相与边框布局，将云纹压暗至近墨蓝黑，增强金线辨识度。v2 以原生 962×1635 无损编码保存，逐像素对比与编辑输出完全一致；不插值放大，也未生成真实 4K。相对 v1 的 680×1160，运行图像素数量约翻倍。资源约 1.28 MiB，增加传输体积以保留细节，全部牌共用一次加载；正面、动画和交互规则保持原有表达。完整编辑提示词见 [v2 生成记录](../../../ProjectDocument/frontend-handoff-assets/cosmic-card-back-v2-prompt.md)。

首页单独将卡牌的 `will-change` 改为 `auto`。浏览器同图、同位置对照确认大幅放大后的细金线更清楚；其他阶段继续使用原有 `will-change: transform`。此改动不调整轨迹、缩放数值、节点尺寸或交互规则。

旧版 `TarotExperience` 继续使用根目录的 `../tarot-card-back.webp`，该旧素材未替换。完整提示词和来源记录见 [生成记录](../../../ProjectDocument/frontend-handoff-assets/cosmic-card-back-v1-prompt.md)。原始生成文件保留在 Codex 本地生成目录，最终运行素材已保存到本目录。
